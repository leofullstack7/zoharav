# ZOHARAV & CO.

Sitio de asesoría en recursos naturales, energía, minería, sostenibilidad e inversión responsable.

## Fase 1

Next.js 15 (App Router), React 19, TypeScript estricto, Tailwind CSS 4, next-intl (inglés por defecto, español en `/es`) y la base de movimiento (GSAP + Lenis).

El copy vive en `content/`. La interfaz corta vive en `messages/en.json` y `messages/es.json`. Lo que cambió respecto del PDF está en `CONTENT-CHANGES.md`.

```bash
npm install
npm run dev
```

Inglés en `/`. Español en `/es`.

## Qué no es este sitio

Zoharav asesora. No extrae, no vende y no transporta petróleo, gas ni minerales. No hay oferta de ciberseguridad, datos, inteligencia artificial ni software.
